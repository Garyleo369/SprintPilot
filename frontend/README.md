# SprintPilot frontend

The existing React + Vite application, implemented in JavaScript. See the [root README](../README.md) for full setup, environment configuration and verification.

From this directory: `npm ci`, then `npm run dev`. The development server proxies `/api` to `http://127.0.0.1:5000`. Start the backend separately. `npm run build` produces `dist/`, which the backend serves in production. `npm run lint` runs Oxlint.
